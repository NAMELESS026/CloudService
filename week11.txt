1. 복습

$ touch [새 파일명.txt]

$ git branch [새 브랜치]
$ git switch [생성한 브랜치]

$ git checkout -b [새 브랜치]




2. 텍스트 파일 수정

$ vi [파일명]
가장 자주 쓰이는 에디터

$ nano [파일명]
(Ctrl+X: 나가기, Ctrl+O: 저장)

$ echo "[입력할 내용]" >> [파일명]
짧은 내용을 입력할 때 보다 간편히 사용 가능




3. 충돌

각 브랜치에 같은 제목의 파일을 여러 개 생성 > 제목이 동일해 커밋 시 충돌
=> git merge로 브랜치 합치기
=> 파일 직접 수정을 통해 충돌 해결 가능
